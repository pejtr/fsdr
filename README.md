- Node.js 22+
- pnpm

- Stripe account (test mode)

```bash

# Install dependencies
```

## 🔑 Key Files & Workflows

### Adding a New Feature
1. **Database:** Update `drizzle/schema.ts`, run `pnpm db:push`
2. **Backend:** Add query helper in `server/db.ts`, then procedure in `server/routers.ts`
3. **Frontend:** Create component in `client/src/pages/` or `client/src/components/`, call tRPC hook
4. **Tests:** Add vitest in `server/*.test.ts`, run `pnpm test`
5. **Checkpoint:** `webdev_save_checkpoint` before merging

### Email Sequences (SendGrid)
- Triggered by `sendEmail()` in `server/revenue-engine.ts`
- Templates: welcome, upsell (day 3), win-back (day 7), abandoned checkout, VIP renewal
- Fallback to in-app notification if SendGrid fails

### Stripe Webhook Flow
1. User completes checkout → Stripe fires `checkout.session.completed`
2. Webhook handler in `server/stripe-webhook.ts` processes event
3. Creates subscription in DB, triggers welcome email, shows upsell popup
4. Weekly revenue report runs Mondays 8:00 UTC (Heartbeat cron)

### Affiliate Tracking
- UTM parameters: `?utm_source=affiliate&utm_medium=referral&utm_campaign=AFFILIATE_CODE`
- Tracked in `affiliateClicks` table with conversion funnel
- Leaderboard updated daily, cash prizes calculated monthly
